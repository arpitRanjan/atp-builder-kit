# Stage 14: the handover

This stage has no notebook. You hand the project to someone who has never seen it. Put here:

- `HANDOFF.md`: start from `templates/HANDOFF.md` and fill in every part.
- `evals_run.txt`: the output of `make evals`.
- `traces_run.txt`: the output of `make traces`.
- A note from someone else (or from you, a day later, on a clean machine) who ran it cold: what broke.
