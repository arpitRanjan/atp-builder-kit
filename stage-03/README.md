# Stage 3: your help assistant, shipped

Put here:

- `CODEMAP.md`: a short map of the code you own: which file does what, and where the prompt lives.
- `prompts/`: every system prompt as a versioned file (`help_v1.md`, `help_v2.md`, ...), never edited in place.
- Your MCP tool: your changes to `mcp_server/server.py`, or a copy of it here, with its tool list and scopes.
- `DEPLOYED.md`: the deployed app URL, the date, who can see it (public or private), and the key's spend cap.
