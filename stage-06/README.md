# Stage 6: an agent, its harness, its context and its outputs

Put here:

- `06_agent_loop.ipynb`: your run of `notebooks/06_agent_loop.ipynb`, with both breaks and the stop that fired for each.
- `06_harness.ipynb`: your run of `notebooks/06_harness.ipynb`, with the pass rate table.

- `06_context_ablation.ipynb`: your run of `notebooks/06_context_ablation.ipynb`: block ablation, compaction, memory.
- `06_structured_output.ipynb`: your run of `notebooks/06_structured_output.ipynb`, with the caught and missed counts.
