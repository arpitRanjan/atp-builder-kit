# About this example

This is an example finished Stage 6, made with the kit's offline mock model (`KIT_OFFLINE=1`).
The numbers are NOT real model results: the mock follows keyword rules (`kit/mock_brain.py`).

Run `notebooks/06_harness.ipynb` and `notebooks/06_context_ablation.ipynb` live with your own key and
your own feature's tasks, then replace every file here with your own runs. Write your own README
sections and your own reading of the failed run.
