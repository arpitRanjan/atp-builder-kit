# About this example

This is an example finished Stage 7, made with the kit's offline mock model (`KIT_OFFLINE=1`).
The approval and feedback rows were written by the kit's own functions (`kit/approval.py`,
`kit/feedback.py`) in scripted sessions, not by real people. Answers come from the mock model.

You must still do these yourself:

- Deploy the app and put `<your live URL>` in the README.
- Collect your own approval rows (6 or more) and feedback rows (3 or more) by using your live app.
- Run the usability test with 3 real people and fill in the table: the example leaves it blank on purpose.
