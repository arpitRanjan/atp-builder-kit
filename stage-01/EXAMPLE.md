# Example stage 1 (offline mock model)

This folder was made by running the kit notebooks with the offline mock model (`KIT_OFFLINE=1`).
The numbers are not real model results. They only show the shape of a finished stage.

What a learner must still do themselves:

- Run both notebooks with a real free tier key (Colab secrets or an environment variable).
- Rewrite the 10 probes in `data/probes.csv` for their own product's help job, with pass criteria, before running.
- Write their own five predictions (Step 9) and README section (Step 10) from their own numbers.
- Share both notebooks so anyone with the link can view, and submit the two links: `<your notebook 1 link>`, `<your notebook 2 link>`.
- Keep `probe_runs.csv` and `probe_summary.csv` for Stages 2 and 4.
