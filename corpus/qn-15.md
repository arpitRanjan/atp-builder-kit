title: Read the audit log
visibility: admin
---
Use the audit log to review important activity in Quillnote, such as sign-ins, note sharing, workspace changes, and admin updates.

- Sign in to Quillnote with an admin account.
- Open **Settings**.
- Select **Audit log**.
- Choose a date range to narrow the results.
- Use filters to show specific events, users, or workspaces.
- Select an entry to view full details.

Each log entry includes:

- **Time** of the action
- **User** who performed it
- **Event type**
- **Target** such as a note, team, or setting
- **Result** such as success or failure
- **IP address** when available

To find a specific issue, start with the date and user filters. Then review related events around the same time.

If you need to keep a record:

- Click **Export**
- Choose **CSV** or **JSON**
- Save the file to a secure location

Keep these points in mind:

- The audit log is read-only
- You cannot edit or delete log entries
- Some events may take a short time to appear
- Access to the audit log is limited to admins only
