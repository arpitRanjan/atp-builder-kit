title: Recover a deleted note
visibility: public
---
If you deleted a note in Quillnote, you can usually restore it from **Trash**.

1. Open **Quillnote**.
2. In the sidebar, select **Trash**.
3. Find the note you want to recover.
4. Open the note, then select **Restore**.

The note returns to its previous notebook. If that notebook no longer exists, Quillnote restores the note to **My Notes**.

## If you cannot find the note

Try these checks:

- Make sure you are signed in to the correct account.
- Use **Search** in Trash to look for the note title or keywords.
- Check whether the note was deleted on another device and has not synced yet.
- Refresh the app or reopen it, then check Trash again.

## Important

- Notes in Trash are kept for **30 days** before permanent removal.
- After a note is permanently deleted, it cannot be recovered in the app.
- If you restored a note by mistake, you can move it back to Trash.

If you need more help, open **Settings > Help** in Quillnote and contact support.
