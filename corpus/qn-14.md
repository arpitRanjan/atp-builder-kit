---
id: qn-14
title: Delete a user's data on request
visibility: admin
---
If a user asks for their data to be deleted, follow these steps in Quillnote:

1. Sign in with an admin account.
2. Open **Admin Console**.
3. Go to **Users** and search for the person by name or email.
4. Open the user record and confirm you have the correct account.
5. Check for anything that should be exported first, such as shared notes, attachments, or audit needs.
6. Ask the user to confirm the request if this has not already been recorded.
7. In the user record, select **Delete user data**.
8. Choose whether to remove:
   - profile details
   - personal notes
   - uploaded files
   - comments and activity history
9. Review the warning message carefully. Deletion is permanent and cannot be undone.
10. Type the required confirmation phrase and select **Confirm deletion**.

After deletion, Quillnote removes the selected data from the active workspace. If your setup includes backups, follow your internal backup retention process as well.

For record keeping, log the request date, the admin who completed it, and the scope of data removed.
