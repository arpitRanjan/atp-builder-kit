To export a note as a PDF in Quillnote:

1. Open the note you want to save.
2. Check the note layout and make any final edits.
3. Select **More** or the **three-dot menu** in the top corner.
4. Choose **Export**.
5. Select **PDF** from the list of file types.
6. If prompted, choose your page size, orientation, or whether to include images.
7. Select **Export** or **Create PDF**.
8. Choose where to save the file on your device.
9. Select **Save**.

If your note includes checklists, tables, or images, review the PDF after export to confirm everything appears correctly.

## Tips

- Use **Print preview** first if that option is available.
- Large images may make the PDF file bigger.
- If the export looks cut off, try a different page orientation.

## If PDF export is unavailable

- Make sure the note is fully synced.
- Update Quillnote to the latest version.
- Try closing and reopening the app, then export again.
